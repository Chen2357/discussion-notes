§I Warm-Up

(Warm-up) Consider the following plan for a hiking trail on a topographic map.

Which of the following graphs best represents the elevation of the trail as a function of time?

Solution. The correct option is Option (B). We can observe the following features of the trail plan:

  • The trail starts at an elevation between 60 and 80, and we are climbing up.
  • At 12pm, we are at an elevation of around 160, and we are still climbing up.
  • After 12pm, we reach a maximum elevation of around 200 and we start to descent.
  • We descent to an elevation just above 140, and we start to climb up again until we reach the end of the trail at an elevation of just above 160.

The only option that satisfies all of these features is Option (B).

Option (A) shows a descent at 12pm, and Option (C) shows a descent at the end of the trail, so they are both incorrect.

§II Composing Curves and Functions

The warm-up exercise above is an example of composing a curve (i.e. a vector valued function) 𝑟⃗(𝑡) with a function 𝑓(𝑥,𝑦) to produce a single-variable function 𝑔(𝑡)=𝑓(𝑟⃗(𝑡)).

Here is a more concrete example. Consider the curve 𝑟⃗(𝑡)=(𝑡,𝑡2) and the function 𝑓(𝑥,𝑦)=𝑥+𝑦. Then the composition 𝑓(𝑟⃗(𝑡)) is obtained by looking at 𝑥+𝑦 and substituting the components of 𝑟⃗(𝑡) via 𝑥=𝑡 and 𝑦=𝑡2, so the end result is

𝑓(𝑟⃗(𝑡))=𝑓(𝑡,𝑡2)=𝑡+𝑡2.

(Exercise) Consider the function 𝑓(𝑥,𝑦)=𝑥𝑦 and two curves 𝑟⃗1(𝑡)=(cos𝑡,sin𝑡) and 𝑟⃗2(𝑡)=(1+𝑡2,𝑡).

  1. Write the composition 𝑤1=𝑓(𝑟⃗1(𝑡)) and 𝑤2=𝑓(𝑟⃗2(𝑡)) as functions of 𝑡.

  2. Compute and verify that the curves 𝑟⃗1(𝑡) and 𝑟⃗2(𝑡) have the same position and velocity vector at 𝑡=0, that is

    𝑟⃗1(0)=𝑟⃗2(0)and𝑟⃗1′(0)=𝑟⃗2′(0).

    Compute the derivatives

    𝑑𝑤1𝑑𝑡and𝑑𝑤2𝑑𝑡

    and verify that the derivatives are equal at 𝑡=0.

  3. If there is a third curve with the same position and velocity vector at 𝑡=0, is it always true that the derivatives of the compositions is the same at 𝑡=0?

Solution.

  1. We have

    𝑤1=cos(𝑡)sin(𝑡)and𝑤2=(1+𝑡2)𝑡=𝑡+𝑡3.

  2. We have

    𝑟⃗1(0)=(cos0,sin0)=(1,0)and𝑟⃗2(0)=(1+02,0)=(1,0),

    and

    𝑟⃗1′(𝑡)=⟨−sin𝑡,cos𝑡⟩⟹𝑟⃗1′(0)=⟨0,1⟩,𝑟⃗2′(𝑡)=⟨2𝑡,1⟩⟹𝑟⃗2′(0)=⟨0,1⟩.

    Therefore, the the curves 𝑟⃗1(𝑡) and 𝑟⃗2(𝑡) have the same position and velocity vector at 𝑡=0. We compute

    𝑑𝑤1𝑑𝑡=cos2𝑡−sin2𝑡⟹[𝑑𝑤1𝑑𝑡]𝑡=0=1,𝑑𝑤2𝑑𝑡=1+3𝑡2⟹[𝑑𝑤2𝑑𝑡]𝑡=0=1.

    The derivatives of 𝑤1 and 𝑤2 are equal at 𝑡=0.

  3. Yes, it is always true! If we have a third curve 𝑟⃗3(𝑡)=(𝑥(𝑡),𝑦(𝑡)) such that (𝑥(0),𝑦(0))=(1,0) and ⟨𝑥′(0),𝑦′(0)⟩=⟨0,1⟩, then we can write

    𝑤3=𝑓(𝑟⃗3(𝑡))=𝑥(𝑡)𝑦(𝑡)

    and compute

    𝑑𝑤3𝑑𝑡=𝑥′(𝑡)𝑦(𝑡)+𝑥(𝑡)𝑦′(𝑡)⟹[𝑑𝑤3𝑑𝑡]𝑡=0=𝑥′(0)𝑦(0)+𝑥(0)𝑦′=0⋅0+1⋅1=1.

    This is also a straight forward consequence of the multivariable chain rule, which we will discuss in the next discussion.

§III Two-Variable Limits

The formal definition of

lim(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦)=𝐿

is not important to us. If 𝑓(𝑥,𝑦) is continuous and well-defined at (𝑥0,𝑦0), then we can simply substitute (𝑥0,𝑦0) into 𝑓(𝑥,𝑦) to get

lim(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦)=𝑓(𝑥0,𝑦0).

If 𝑓(𝑥,𝑦) is not well-defined at (𝑥0,𝑦0), then we have three strategies at our disposal.

  1. Rewrite 𝑓(𝑥,𝑦) into a function that agrees with 𝑓(𝑥,𝑦) near (𝑥0,𝑦0) and is well-defined at (𝑥0,𝑦0). For example, if we look at

    lim(𝑥,𝑦)→(1,1)𝑥2−𝑦2𝑥−𝑦,

    we see that we cannot substitute (0,0) in, but we can factor the numerator to get

    lim(𝑥,𝑦)→(1,1)(𝑥−𝑦)(𝑥+𝑦)𝑥−𝑦=lim(𝑥,𝑦)→(1,1)(𝑥+𝑦)=2.

  2. Another strategy is to use the sandwich theorem. If we look at

    lim(𝑥,𝑦)→(0,0)𝑥sin(1𝑦),

    then we can use the fact that −1≤sin(1𝑦)≤1 to get

    −𝑥≤𝑥sin(1𝑦)≤𝑥.

    The limits of both the left and right hand sides as (𝑥,𝑦)→(0,0) are 0, so by the sandwich theorem, we have

    lim(𝑥,𝑦)→(0,0)𝑥sin(1𝑦)=0.
  3. The third strategy is to expand a function into its Taylor series. I will leave this for you to discover in the following exercise.
L’Hôpital’s rule is not one of the three strategies! We can only use L’Hôpital’s rule for single-variable limits.

(Exercise) The following limits correspond to the three strategies: rewriting, sandwich, Taylor. Evaluate them.

  1. lim(𝑥,𝑦)→(4,3)𝑥−𝑦+1𝑥−𝑦−1
  2. lim(𝑥,𝑦)→(0,0)𝑥𝑦2𝑥2+𝑦2
  3. lim(𝑥,𝑦)→(0,0)sin(𝑥𝑦)𝑥𝑦

Solution.

  1. We can rewrite

    𝑥−𝑦+1𝑥−𝑦−1=𝑥−𝑦+1(𝑥−𝑦+1)(𝑥+𝑦+1)=1𝑥+𝑦+1,

    and so

    lim(𝑥,𝑦)→(4,3)𝑥−𝑦+1𝑥−𝑦−1=lim(𝑥,𝑦)→(4,3)1𝑥+𝑦+1=14.

  2. We have

    |𝑥𝑦2𝑥2+𝑦2|=|𝑥|(𝑦2𝑥2+𝑦2)≤|𝑥|

    and so

    −|𝑥|≤𝑥𝑦2𝑥2+𝑦2≤|𝑥|.

    The limits of both the left and right hand sides as (𝑥,𝑦)→(0,0) are 0, so we have

    lim(𝑥,𝑦)→(0,0)𝑥𝑦2𝑥2+𝑦2=0.

  3. We can use the Taylor series expansion of sin(𝑥𝑦) to get

    sin(𝑥𝑦)=𝑥𝑦−(𝑥𝑦)33!+(𝑥𝑦)55!−⋯

    and so

    lim(𝑥,𝑦)→(0,0)sin(𝑥𝑦)𝑥𝑦=lim(𝑥,𝑦)→(0,0)(1−(𝑥𝑦)23!+(𝑥𝑦)45!−⋯)=1.

To show that a two-variable limit does not exist, we need to find two different curves to (𝑥0,𝑦0) along which 𝑓(𝑥,𝑦) approaches different limits. The most general curve is a vector valued function 𝑟⃗(𝑡) such that 𝑟⃗(𝑡0)=(𝑥0,𝑦0) for some 𝑡0, and then we will look at the limit of 𝑓(𝑟⃗(𝑡)) as 𝑡→𝑡0.

In practice however, we just look at curves that are graphs of functions 𝑦=𝑔(𝑥) that pass through (𝑥0,𝑦0). If 𝑔(𝑥0)=𝑦0, then we can evaluate the limit of 𝑓(𝑥,𝑦) along the curve by

lim𝑦=𝑔(𝑥)(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦)=lim𝑥→𝑥0𝑓(𝑥,𝑔(𝑥)).

If we can find two paths 𝑦=𝑔1(𝑥) and 𝑦=𝑔2(𝑥) with 𝑦0=𝑔1(𝑥0)=𝑔2(𝑥0) such that

lim𝑦=𝑔1(𝑥)(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦)≠lim𝑦=𝑔2(𝑥)(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦),

then we can conclude that the two-variable limit

lim(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦)does not exist.

We can describe a path using 𝑥=ℎ(𝑦) also, we will similarly evaluate the limit along this path by

lim𝑥=ℎ(𝑦)(𝑥,𝑦)→(𝑥0,𝑦0)𝑓(𝑥,𝑦)=lim𝑦→𝑦0𝑓(ℎ(𝑦),𝑦)

and if this is different from the limit along some other path, then we can also conclude that the two-variable limit does not exist.

For example, we can show that the limit

lim(𝑥,𝑦)→(0,0)𝑦𝑥

does not exist by evaluating the limit along the paths 𝑦=𝑘𝑥:

lim𝑦=𝑘𝑥(𝑥,𝑦)→(0,0)𝑦𝑥=lim𝑥→0𝑘𝑥𝑥=𝑘.

Since the limit depends on the value of 𝑘, we can conclude that the two-variable limit does not exist.

Usually straight line paths will suffice. On the rare occasion where it does not, we can try parabolas 𝑦=𝑘𝑥2.

(Exercise) Show that lim(𝑥,𝑦)→(1,1)𝑥𝑦2−1𝑦−1 does not exist. Hint: try the following curves through (1,1).

Solution. The two paths in the hint are 𝑥=1 (the red line) and 𝑦=𝑥 (the blue line).

  • Along the path 𝑥=1, we have

    lim𝑥=1(𝑥,𝑦)→(1,1)𝑥𝑦2−1𝑦−1=lim𝑦→1𝑦2−1𝑦−1=lim𝑦→1(𝑦+1)=2.

  • Along the path 𝑦=𝑥, we have

    lim𝑦=𝑥(𝑥,𝑦)→(1,1)𝑥𝑦2−1𝑦−1=lim𝑥→1𝑥3−1𝑥−1=lim𝑥→1(𝑥2+𝑥+1)=3.

Since the two limits are different, we can conclude that

lim(𝑥,𝑦)→(1,1)𝑥𝑦2−1𝑦−1does not exist.
