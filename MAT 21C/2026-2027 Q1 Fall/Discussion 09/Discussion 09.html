§I Warm-Up

(Warm-up) The level curves of the function 𝑓(𝑥,𝑦)=12𝑥+5𝑦 are shown below. Among points on the unit circle 𝑥2+𝑦2=1, what is the maximum value of 𝑓(𝑥,𝑦)? Where does it occur?

Solution. If we were to test whether we can hit the ceiling with a wooden stick, we better point it straight up in the direction perpendicular to the ceiling. Same reasoning applies here: we are pointing a stick with unit length from the origin, and we want to see what is the furthest level curve we can reach. Thus, we better point the stick in the direction perpendicular to the level curves 12𝑥+5𝑦=𝑐, which is ⟨12,5⟩. The unit vector in that direction is

𝑢⃗=1122+52⟨12,5⟩=⟨1213,513⟩.

Therefore, the maximum value of 𝑓(𝑥,𝑦) on the unit circle occurs at (𝑥,𝑦)=(1213,513), and the maximum value is

𝑓(1213,513)=12⋅1213+5⋅513=16913=13.

Yet another way to solve the problem is to reframe the problem as maximizing 𝑢⃗⋅⟨12,5⟩ among all unit vectors 𝑢⃗. We know by the formula

𝑢⃗⋅⟨12,5⟩=|𝑢⃗||⟨12,5⟩|cos(𝜃)=122+52cos(𝜃)

that the maximum occurs when 𝜃=0, i.e. when 𝑢⃗ points in the same direction as ⟨12,5⟩, and the maximum value is 122+52=13.

There are two takeaways from the warm-up problem.

  • The gradient vector, which is

    ∇𝑓=⟨𝜕𝑓𝜕𝑥,𝜕𝑓𝜕𝑦⟩=⟨12,5⟩,

    is perpendicular to the level curves of 𝑓(𝑥,𝑦).

  • The gradient vector of 𝑓(𝑥,𝑦) points in the direction of the steepest increase of 𝑓(𝑥,𝑦), exactly in the sense of the wooden stick.

§II Gradient

In general, the gradient of a function 𝑓(𝑥,𝑦) is defined as

∇𝑓=⟨𝜕𝑓𝜕𝑥,𝜕𝑓𝜕𝑦⟩.

The gradient can be used to approximate the change of 𝑓(𝑥,𝑦) for small changes in 𝑥 and 𝑦. Recall from last discussion that the difference 𝑓(𝑥+𝑑𝑥,𝑦+𝑑𝑦)−𝑓(𝑥,𝑦) for small 𝑑𝑥 and 𝑑𝑦 can be approximated by

𝜕𝑓𝜕𝑥𝑑𝑥+𝜕𝑓𝜕𝑦𝑑𝑦=⟨𝜕𝑓𝜕𝑥,𝜕𝑓𝜕𝑦⟩⋅⟨𝑑𝑥,𝑑𝑦⟩=∇𝑓⋅⟨𝑑𝑥,𝑑𝑦⟩.

The geometric meanings of the gradient are all coming from this formula.

  1. The gradient points in the direction of the steepest increase, meaning that the directional derivative

    𝐷𝑢⃗𝑓=∇𝑓⋅𝑢⃗

    is the greatest among unit vectors 𝑢 precisely when 𝑢 points in the same direction as the gradient. This is for the exact same reason as the warm-up problem (see Figure 2). The magnitude of the gradient |∇𝑓| is precisely the value of the greatest directional derivative.

  2. The gradient of 𝑓(𝑥,𝑦) is perpendicular to the level curves, and so it is a normal vector to the tangent line of the level curve. In particular, the tangent line to the level curve of 𝑓(𝑥,𝑦) at (𝑥0,𝑦0) is given by

    ∇𝑓(𝑥0,𝑦0)⋅⟨𝑥−𝑥0,𝑦−𝑦0⟩=0.

    In 3-dimensions, the tangent plane to the level surface of 𝑓(𝑥,𝑦,𝑧) at (𝑥0,𝑦0,𝑧0) is given by

    ∇𝑓(𝑥0,𝑦0,𝑧0)⋅⟨𝑥−𝑥0,𝑦−𝑦0,𝑧−𝑧0⟩=0.
  3. We must have ∇𝑓(𝑥,𝑦)=⟨0,0⟩ at a local maximum or minimum of 𝑓(𝑥,𝑦). After all, if the gradient is nonzero, then we can move in that direction to increase or move in the opposite direction to decrease the value of 𝑓(𝑥,𝑦). The points where ∇𝑓(𝑥,𝑦)=⟨0,0⟩ are called critical points of 𝑓(𝑥,𝑦).

(Exercise)

  1. Find the gradient of 𝑓(𝑥,𝑦)=𝑥2−𝑥𝑦+12𝑦2+3. Then, evaluate ∇𝑓(3,2).

  2. Use the approximation formula

    𝑓(𝑥+𝑑𝑥,𝑦+𝑑𝑦)−𝑓(𝑥,𝑦)≈𝜕𝑓𝜕𝑥𝑑𝑥+𝜕𝑓𝜕𝑦𝑑𝑦,

    to approximate 𝑓(3.01,2.1).

  3. The approximation we obtained in the previous part is called the linear approximation, we denote it by 𝐿(3.01,2.1). The error 𝐸(3.01,2.1)=𝑓(3.01,2.1)−𝐿(3.01,2.1) is bounded by

    |𝐸(3.01,2.1)|≤12𝑀(|3.01−3|+|2.1−2|)2

    where 𝑀 must be an upper bound of |𝑓𝑥𝑥|, |𝑓𝑦𝑦|, and |𝑓𝑥𝑦| for all points 3≤𝑥≤3.01 and 2≤𝑦≤2.1. Find the error bound.

  4. Find the only critical point of 𝑓(𝑥,𝑦). Do you think it is a local maximum, local minimum, or neither?

Solution.

  1. The gradient of 𝑓(𝑥,𝑦) is

    ∇𝑓=⟨𝜕𝑓𝜕𝑥,𝜕𝑓𝜕𝑦⟩=⟨2𝑥−𝑦,−𝑥+𝑦⟩.

    Evaluating at (3,2), we get

    ∇𝑓(3,2)=⟨4,−1⟩.

  2. Rearrange the approximation formula, we have

    𝑓(𝑥+𝑑𝑥,𝑦+𝑑𝑦)≈𝑓(𝑥,𝑦)+𝜕𝑓𝜕𝑥𝑑𝑥+𝜕𝑓𝜕𝑦𝑑𝑦.

    Plugging in 𝑥=3, 𝑦=2, and 𝑑𝑥=0.01, 𝑑𝑦=0.1, we have

    𝑓(3,2)=32−3⋅2+12⋅22+3=8,𝜕𝑓𝜕𝑥(3,2)=2⋅3−2=4,𝜕𝑓𝜕𝑦(3,2)=−3+2,

    and so

    𝑓(3.01,2.1)≈𝑓(3,2)+𝜕𝑓𝜕𝑥(3,2)𝑑𝑥+𝜕𝑓𝜕𝑦(3,2)𝑑𝑦=8+4(0.01)−1(0.1)=7.94.

  3. Note that we are defining

    𝐿(𝑥,𝑦)=𝑓(3,2)+𝜕𝑓𝜕𝑥(3,2)(𝑥−3)+𝜕𝑓𝜕𝑦(3,2)(𝑦−2),

    so that 𝐿(3.01,2.1)=7.94. The second derivatives of 𝑓(𝑥,𝑦) are

    𝑓𝑥𝑥=2,𝑓𝑦𝑦=1,𝑓𝑥𝑦=−1.

    Thus, we can take 𝑀=2 as an upper bound for the second derivatives, and the error is bounded by

    |𝐸(3.01,2.1)|≤12⋅2(|3.01−3|+|2.1−2|)2=0.0121.

    This tells us that the actual value of 𝑓(3.01,2.1) is between 7.94−0.0121 and 7.94+0.0121.

  4. We have found in the part (a) that

    ∇𝑓=⟨2𝑥−𝑦,−𝑥+𝑦⟩.

    Setting the gradient to zero, we get

    2𝑥−𝑦=0,−𝑥+𝑦=0.

    Solving the system of equations, we get the critical point (0,0).

    If we look at the single-variable functions 𝑓(𝑥,0)=𝑥2+3 and 𝑓(0,𝑦)=12𝑦2+3, we see that they are both parabolas that open upward, so the critical point (0,0) cannot be a local maximum. Can we conclude that it is a local minimum? Not yet, because of the −𝑥𝑦 term, we cannot rule out the possibility that the function dips below 3. We need a more systematic way to classify the critical point, which we will discuss in the next section.

In general, the linear approximation of a function 𝑓(𝑥,𝑦) at a point (𝑥0,𝑦0) is given by

𝐿(𝑥,𝑦)=𝑓(𝑥0,𝑦0)+∇𝑓(𝑥0,𝑦0)⋅⟨𝑥−𝑥0,𝑦−𝑦0⟩.

The error of the linear approximation on a rectangle containing (𝑥0,𝑦0) is bounded by

|𝐸(𝑥,𝑦)|≤12𝑀(|𝑥−𝑥0|+|𝑦−𝑦0|)2

where 𝑀 is an upper bound of the second derivatives of 𝑓 for all points in the rectangle.

§III Second Derivative Test

If we want to find the local extrema of a function 𝑓(𝑥) of one variable, we can find the critical points by solving 𝑓′(𝑥)=0, and then determine which critical points are local maxima or local minima by using the second derivative test. To recap, the second derivative test for one variable says that:

  • If 𝑓″(𝑥)>0, then the function is “happy” (curving upward), so the critical point is a local minimum.
  • If 𝑓″(𝑥)<0, then the function is “sad” (curving downward), so the critical point is a local maximum.

For a function 𝑓(𝑥,𝑦) of two variables, we can find the critical points by solving

∇𝑓(𝑥,𝑦)=⟨0,0⟩,

or equivalently, by solving the system of equations

𝑓𝑥(𝑥,𝑦)=0,𝑓𝑦(𝑥,𝑦)=0.

At critical points, the function is flat like the one variable case. A naive classification of the critical points might be to just look at the second derivatives 𝑓𝑥𝑥 and 𝑓𝑦𝑦:

  • A local maximum is curving downward in both directions, so we expect 𝑓𝑥𝑥<0 and 𝑓𝑦𝑦<0.
  • A local minimum is curving upward in both directions, so we expect 𝑓𝑥𝑥>0 and 𝑓𝑦𝑦>0.
  • If 𝑓𝑥𝑥 and 𝑓𝑦𝑦 have different signs, then the function is curving upward in one direction and curving downward in the other, so the critical point is a saddle point.

This characterization is almost complete. The fact that a surface is curving upward in both axes directions does not mean that it is curving upward in all directions: if it dips along the diagonal, then it is a saddle after all.

To take the diagonal effect into account, the complete second derivative test for two variables look at the so-called discriminant 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2.

  • If 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2>0 and 𝑓𝑥𝑥>0 (or 𝑓𝑦𝑦>0), then the critical point is a local minimum.
  • If 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2>0 and 𝑓𝑥𝑥<0 (or 𝑓𝑦𝑦<0), then the critical point is a local maximum.
  • If 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2<0, then the critical point is a saddle point.
  • If 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2=0, the test is inconclusive.

Note that our naive classification is a special case of the discriminant test.

  • For local extrema, we have 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2>0 which can only happen when 𝑓𝑥𝑥 and 𝑓𝑦𝑦 have the same sign.
  • When 𝑓𝑥𝑥 and 𝑓𝑦𝑦 have different signs, we are guaranteed to have 𝑓𝑥𝑥𝑓𝑦𝑦−𝑓𝑥𝑦2<0, so it is a saddle point.
